# SDSU AI Club — Overview

The AI Club at San Diego State University. Officers use a Discord server for communication. The agent was initialized January 21, 2026 to support club operations.

## Club structure
- **Officers** communicate in `officer-general` Discord channel (#976908028739723314)
- **Agent responses** go to `agent` channel (#1463362044727267521)
- **Email digest** goes to `email` channel (#1464343247328641167)
- **Live chat** in `agent-live` channel (#1528473565148479651) via Letta Code channels
- **Feedback** via `agent-feedback` channel (routes separately to Letta)
- Group formation rule: exactly 4 members per project group
