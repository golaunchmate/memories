### KEY TECHNICAL SHIFT:

**FROM:** Pre-generated dialogue trees (static, branching "if user says this, then NPC says that")  
**TO:** Dynamic chat box interactions (LLM calls during gameplay, NPCs have memory state + personality layers)

**How It Works Now:**
1. User prompts story concept
2. Narrative engine (LLM) generates:
   - List of NPCs (with hidden personality + public-facing persona)
   - List of areas
   - Chapter-by-chapter breakdown of story progression
3. World generation pipeline creates 3D world + places NPCs
4. Each NPC has memory state (tracks player interactions, game state)
5. During gameplay, player types natural language → NPC responds dynamically via LLM

**Example:** Graveyard keeper NPC knows internally "I saw the ghost, I know everything" but tells player "I need to save my job, so I won't reveal everything." Hidden motives + public persona = Infocom-style narrative depth.

**Cost:** ~$7 per world (40 assets × $0.175/asset), ~1 GB file size
