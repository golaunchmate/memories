## CORE INSIGHT: Growing Agents + Feedback Loops

**Three feedback loops for agent growth:**
1. **Context Loop** - Bringing context back into agent (standard growth)
2. **Integration Loop** - ClaudeBot/MoltBot approach with local file access
3. **Self-Learning Loop** - Agents learning from interactions over time, improving across cohort

**Key Discovery:** Specialized agents have unique properties as they grow through chat history. This "magic" can't be replicated by just copying memory blocks - the chat history growth creates unknown but profound capabilities.

---

## TIDBITS → MORSELS EVOLUTION

**Tidbits:** Surface learnings from chat, share with others
**Morsels (expanded):** Multiplayer features - QR codes, participant tracking in presentations

**Post-consumption feedback loop problem:**
- Tidbits take us from AGENT WORLD → HUMAN WORLD
- If reader gets confused, where does feedback go?

**Option A (Human World):** Click confused slide → hyper-navigate to Messages app → text person directly
**Option B (Agent World - Simple):** Append tidbit to URL → login → message owner (agent ID stored in tidbit)
**Option C (Agent World - Advanced):** Reader accesses owner's agent via CONVERSATION THREAD (partitioned access - same memory blocks, no chat history access)

**Concern:** Giving guest access to someone's agent = security/permission design needed

## SPECIALIZED AGENT SCALING PROBLEM

**The Problem:** Can't scale specialized agents because:
- Conversation threads (same memory, no chat history) don't replicate the growth magic
- The context window growth has "deeply profound impacts on functionality"

**Craig's Current Manual Process:**
1. Drop founder context into his specialized agent
2. Get insights
3. Relay back to founder via text or their agent

**Proposed Solution - Link Sharing:**
1. Craig shares specialized agent via web link
2. Founder clicks link → direct agent access
3. Founder chats, gets insights
4. Option to add agent to their profile for ongoing access
5. Shared agent = everyone sees interactions (for now)
6. Future: partition/filter by user

**Benefit:** Specialized agent grows from ALL founder interactions

**Advanced Architecture (future):**
- Supervisor specialized agent (master)
- Sub-agents deployed to founders
- Sub-agents report learnings back to supervisor
- Supervisor pushes updates down to sub-agents
- Maintains feedback loop of growth
