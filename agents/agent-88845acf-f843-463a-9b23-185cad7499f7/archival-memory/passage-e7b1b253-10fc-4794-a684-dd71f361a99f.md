## MAJOR FEATURE: AGENT POKES (Michael)

**What it is:**
- Scheduled messages that trigger agents to take action
- One-time or recurring
- "Auto" button that autofills instruction + date/time based on agent context (the "LoRa" feature)

**Technical Details:**
- Uses Letta conversation threads for auto thinking (keeps main context clean)
- Emits JSON object that gets parsed and saved
- Can manage, reorder, delete pokes
- Pokes stored on Letta server (not Supabase)

**Craig's Reaction:**
- "This is so good! This is mind-blowing!"
- "This allows LaunchMate to become proactive"
- "The big difference is heartbeats - not just request-response"

**Craig's Poke Example:**
- "What should be top of mind for me today? Then send it as an email to clauer@gmail.com with subject 'LaunchMate Daily Briefing'. Run every morning at 7am."
