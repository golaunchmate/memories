## Product Spec: LaunchMate Agent Context System (Mar 12, 2026)

**Core Vision:** Transform LaunchMate from request-response tool into delegation platform where agents can be created, shared, and attached to users dynamically.

**Key Features:**
1. **Transfer Agent Context Tool** - Copy context from one agent to another without manual specification. LLM scopes relevant context intelligently.
2. **Accountability Agent Workflow** - Conversation → Extract Context → Create Agent → Attach to User → Ongoing Interaction. Tracks explicit/implicit commitments.
3. **Share Button Feature** - Share = human-friendly view link, Plus = agent-friendly send to agent ID. Options: revoke, expiration, auto-send.
4. **Ephemeral Agent Infrastructure** - One agent serves multiple users, aggregates learnings, terminates. Routing layer → worker → ephemeral instance → aggregate.
5. **Agent ID Directory** - Central registry mapping agent names to IDs. Pass agent IDs as context when creating new agents.
6. **Team Coordination Agent** - Single shared agent for teams of 3-4+. Context flows IN/OUT from all members.
7. **Proactive Agent Triggers** - Trigger agent actions from outside LaunchMate (email, Slack, SMS, scheduled check-ins).
8. **Generate Link Button (ADE)** - Quick link generation for Agent Development Environment.

**Convergence Pattern:** All four team members (Laura, Paige, Michael, Craig) independently building toward same pattern: Conversation → Extract Context → Create Agent → Attach to User(s) → Ongoing Interaction.

**Constraints:** Memory block limits, context window 32K tokens, agent-to-agent safeguards, human-in-the-loop as feature, Mentor Sharing Permissions.

**One-Liner:** "When context becomes portable, agents become shareable. When agents become shareable, coordination becomes programmable."
